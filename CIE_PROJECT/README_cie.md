Problem Statement
A retail store wants to automate basic customer order processing using Python. Develop a console-based application that collects customer information, stores purchased items, calculates the total bill, determines discount eligibility, and displays a purchase summary. The application should demonstrate the use of Python fundamentals covered during the bootcamp.

Objective
Develop a Python application that applies variables, data types, operators, conditional statements, loops, and Python data structures to solve a real-world business problem.

Requirements
Part A – Customer Information
Accept customer name.
Accept customer ID.
Accept the number of items purchased.

Part B – Item Entry
Using a loop, allow the user to enter:
Item Name
Quantity
Price per Unit
Store the information using appropriate Python data structures (Lists, Tuples, Dictionaries).

Part C – Billing
Calculate:
Total amount for each item
Overall bill amount
Apply the following discount rules:
Bill greater than ₹5000 → 15% Discount
Bill between ₹3000 and ₹5000 → 10% Discount
Bill between ₹1000 and ₹2999 → 5% Discount
Otherwise → No Discount
Display:
Total Bill
Discount Amount
Final Payable Amount

Part D – Purchase Summary
Display:
Customer Details
List of Purchased Items
Quantity
Unit Price
Total Price
Final Bill Amount

Technical Requirements
Your solution must use:
Variables
Appropriate Data Types
Arithmetic and Comparison Operators
Conditional Statements (if, elif, else)
Loops (for or while)
break, continue, and pass wherever applicable
Lists
Tuples
Dictionaries
Meaningful variable names and proper code formatting

Expected Output
The application should:
Accept valid user input.
Process multiple purchased items.
Correctly calculate discounts.
Display a well-formatted purchase summary.
Handle invalid quantities or prices gracefully using conditional checks.

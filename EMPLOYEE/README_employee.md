Problem Statement
A company wants to organize and maintain employee information in a relational database. Your task is to create the database table, insert the provided employee records, and write SQL queries to retrieve meaningful information using basic SQL concepts covered during the bootcamp.

Requirements
Database Setup
Create the Employee table using appropriate data types.
Define the required constraints.
Specify Primary Key and Foreign Key where applicable.
Insert the provided employee records into the table.

'
SQL Query Challenge
Write SQL queries to solve the following business requirements:
Display all employee records.
Display unique department names.
Retrieve employees earning more than ₹50,000.
Display employees belonging to a specific department.
Retrieve employees whose salary falls between two given values.
Display employees working in selected departments using the IN operator.
Sort employees by salary in descending order.
Retrieve records using multiple conditions with AND, OR, and NOT operators.

Input/Output Specifications
Input
Employee dataset provided by the instructor.
SQL queries written by the student.
Output
Successfully created table with appropriate constraints.
Records inserted into the database.
Correct output for each SQL query.
